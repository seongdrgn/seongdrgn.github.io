# seongdrgn.github.io

Personal academic website of **Seongyong Kim** — Ph.D. candidate in Mechanical Engineering at Dongguk University.

🔗 https://seongdrgn.github.io

Built with [Jekyll](https://jekyllrb.com/) on the
[AcademicPages](https://github.com/academicpages/academicpages.github.io) template and hosted on GitHub Pages.

## Content

- `_pages/about.md` — homepage (intro + publications)
- `_publications/` — publication entries
- `_data/` — site data (navigation, author, CV)
- `files/`, `images/` — assets (papers, figures, CV)
- `_config.yml` — site configuration

## Local preview

```bash
bundle install
bundle exec jekyll serve --livereload
# open http://localhost:4000
```
